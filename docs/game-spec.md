# Юный Эколог: описание игры (game-spec)

Этот файл главный источник правды по игре. Если идея меняется, сначала обновляем этот файл.

Дата последнего обновления: 16 ноября 2026 (версия для 3D)

---

## 1. Коротко об игре

- **Название:** Юный Эколог
- **Идея:** герой бежит по 3D-дороге с тремя дорожками (как в Temple Run), отвечает на экологические вопросы, перебегая в окно с правильным ответом, и собирает семена.
- **Цель игрока:** правильно ответить на все задания раздела и получить медаль «Юный эколог».
- **Аудитория:** школьники 1-11 классов.
- **Язык:** русский.
- **Использование:** уроки экологии в школе, игра на телефонах, планшетах, компьютерах.

## 2. Технические решения

| Вопрос | Решение |
|---|---|
| Вид игры | **Настоящее 3D**: камера за спиной героя, три дорожки. Картинки животных и предметов висят на плоских «воротах» в 3D-мире |
| Технология | JavaScript + **Three.js** (Phaser больше не используется, он только для 2D) |
| Формат | PWA: устанавливается на главный экран, работает без интернета |
| Интернет | Нужен только для первой загрузки и обновлений |
| Устройства | iPhone, Android, компьютер (Chrome, Edge, Safari) |
| Положение экрана | Основное: вертикальное на телефоне; игра должна подстраиваться и под горизонтальный экран |
| Герои | Готовые бесплатные 3D-модели KayKit Adventurers 2.0 (лицензия CC0), 6 штук |
| Стиль | Мягкий low-poly (из простых граней), яркие дружелюбные цвета |
| Производительность | Цель: плавная игра на среднем телефоне; без настоящих теней, ограничение разрешения экрана, простая геометрия |
| Ожидаемый размер | Около 10-20 МБ |

### Управление

- **Телефон и планшет:** свайп влево или вправо, а также касание левой или правой половины экрана.
- **Компьютер:** стрелки ← → или клавиши A и D.
- Прокрутка страницы и увеличение двойным касанием во время игры отключены.

## 3. Экраны игры (по порядку)

1. **Заставка и загрузка.** Логотип и полоска «Загрузка…». Игра подгружает модели, картинки и звуки.
2. **«Нажми, чтобы начать».** Телефоны не разрешают звук без касания, поэтому музыка стартует с этого касания.
3. **Выбор персонажа.** 3D-герой стоит в позе ожидания, внизу кнопка «Играть». Свайп влево-вправо переключает героев (всего 6).
4. **Выбор раздела.** Три карточки: **1-4 классы**, **5-8 классы**, **9-11 классы**. Внизу кнопка «Главная».
5. **Игра.**
6. **Конец игры:**
   - победа: герой смотрит на игрока с медалью «Юный эколог» на груди;
   - поражение: кнопки «Ещё раз» и «Главная».

В игре **нет уровней** внутри раздела. Игрок выбирает свой класс, играет и повторяет, пока не победит.

## 4. Правила игры

### Дорога

- Герой бежит по дороге с заборами по бокам (вид сзади).
- Дорожек три.
- Герой перемещается между дорожками.

### Что встречается на дороге

- **Семена.** Дают очки, при сборе звучит звук.
- **Дорожное ограждение.** Обходится по другой дорожке; при ударе теряется сердце.
- **Дыры.** Обходятся по другой дорожке; при падении теряется сердце.
- **Ворота с заданием.** Вопрос сверху, варианты в окнах на дорожках.

### Верхняя панель

- Слева: очки. Очки начисляются за собранные семена и за правильные ответы.
- Справа: три красных сердца (жизни).

### Правила ворот с заданием

- Если вариантов три, они занимают все три дорожки.
- Если вариантов два, третья дорожка закрыта барьером или дырой.
- На дороге всегда должна быть хотя бы одна свободная дорожка, либо дорожка с правильным ответом.
- Дыры и ограждения не должны ставиться так, чтобы пройти было невозможно.

### Ответы

- **Правильный ответ:**
  - окно зеленеет;
  - на фоне вырастает дерево (растущий лес);
  - начисляются очки.
- **Неправильный ответ:**
  - выбранное окно краснеет;
  - персонаж мерцает;
  - правильное окно зеленеет (подсказка после ошибки);
  - мир становится серым и грустным, и возвращается постепенно;
  - игрок теряет одно сердце.
- Победа даёт «растущий лес», и по мере правильных ответов лес становится полнее.

### Столкновения (ограждение и дыра)

При ударе в дорожное ограждение или падении в дыру:
- персонаж мерцает;
- игрок теряет одно сердце;
- персонаж продолжает бежать (игра не останавливается).

Цвет мира при столкновении не меняется (серым мир становится только после неправильного ответа).

### Жизни и конец игры

- У игрока три сердца. Сердце теряется в трёх случаях:
  - неправильный ответ;
  - удар в дорожное ограждение;
  - падение в дыру.
- Потерянное сердце становится серым.
- Когда последнее (третье) сердце становится серым, игра окончена.
- После проигрыша выбор: «Ещё раз» или «Главная».
- Победа: игрок прошёл заданное количество заданий и получил медаль «Юный эколог».

### Скорость

- Скорость постепенно растёт во время игры.
- Максимальная скорость ограничена, чтобы игра оставалась пригодной для детей.

### Выбор заданий

- Задания выбираются случайно из базы раздела.
- Количество заданий до победы задаётся настройкой (см. «Открытые вопросы»).
- В одной игре одно и то же задание не повторяется.

## 5. Задания и вопросы

Категории: название животного, где живёт, чем питается, группа животных, сортировка мусора, экологичные и вредные поступки, экологичные предметы.

Требования:
- Вопросы и варианты ответов хранятся отдельно, не в коде, чтобы их было удобно редактировать.
- Для 1-4 классов в категориях «Где живёт» и «Чем питается» фото животного показывается сверху. Для остальных классов вопросы с животными только текстом.
- Все вопросы проверяет преподаватель.

## 6. Герои

- Всего **6 героев** (вместо прежних 4): Рейнджер, Рыцарь, Маг, Варвар, Разбойник, Разбойник в капюшоне.
- Источник: KayKit Adventurers 2.0 (Kay Lousberg), лицензия CC0. Указывать автора необязательно, но желательно.
- два нужных вида получаются из одной модели: спереди (выбор героя и финиш), со спины (бег по дороге).
- Анимации из набора: ожидание (Idle_A), бег (Running_A, Running_B). Нужна ли анимация радости на финише, решим при разработке.
- Оружие в игре не используется. Одежду по возможности перекрасить в экологическую тему (цвета берутся из маленьких текстур PNG).
- Выбираются свайпом на экране выбора персонажа.
- Медаль: простая 3D-модель, висит на груди героя на финише.

## 7. Звук

- Музыка в меню.
- Музыка в игре.
- Кнопка выключения музыки в главном меню.
- Звуки: сбор семени, правильный ответ, ошибка, победа, проигрыш.
- Только материалы со свободной лицензией (CC0) или собственные.

## 8. Материалы

| Материал | Источник и статус |
|---|---|
| 6 героев с анимациями | Есть (KayKit, CC0) |
| Картинки животных и экологичных предметов | Есть, нужна проверка качества (см. открытый вопрос 8) |
| 3D-дорога, забор, ограждение, дыра, семя, деревья, баки | Создаём в игре из простых форм, либо берём готовые CC0-модели (Kenney, Quaternius, KayKit) |
| Медаль | Создаём сами |
| Музыка и звуки | Нужно найти (CC0) |
| Логотип и значок приложения | Нужно подготовить |

Для каждого материала записывать источник и лицензию.

## 9. План разработки (по этапам)

1. **Основа.** Дорога, бегущий герой, три дорожки, управление. Проверяем на телефонах, не тормозит ли.
2. **Меню.** Загрузка, «Нажми, чтобы начать», выбор героя (6 штук), выбор раздела (1-4, 5-8, 9-11).
3. **Препятствия.** Ограждения, дыры, семена, сердца, мерцание при ударе.
4. **Задания.** Ворота с вопросами и картинками. Вопросы лежат в отдельном файле, который можно редактировать.
5. **Лес и ошибки.** Растёт лес при верном ответе, мир серый при ошибке, красное и зелёное окно, конец игры.
6. **Баланс и финиш.** Скорость, сколько заданий до победы, медаль на груди героя.
7. **Оформление.** Перекраска героев, звуки и музыка, логотип, красивая загрузка.
8. **Офлайн.** Установка на главный экран, проверка в режиме «в самолёте».
9. **Проверка с детьми.** Настройка сложности. Вопросы проверяет преподаватель.


После каждого этапа сохранять копию папки проекта (v1, v2…) и проверять игру на телефоне.

## 10. Проверка перед показом детям

- [ ] Игра установлена на главный экран iPhone.
- [ ] Игра установлена на Android.
- [ ] В режиме «в самолёте» открывается и проходится целиком (картинки, модели, музыка).
- [ ] Музыка включается после касания.
- [ ] Игра не тормозит на самом слабом телефоне из тех, что будут в классе.
- [ ] Тексты и картинки в окнах читаются на маленьком телефоне.
- [ ] Все вопросы проверены преподавателем.

## 11. Открытые вопросы и задачи

1. Сколько заданий нужно пройти до медали (например, 15 или 20)?
2. Задания и вопросы готовы и разделены по категориям, но надо определить, каких заданий должно быть больше, и решить, сколько заданий брать из каждой категории для каждого раздела, потому что не все задания одинаково интересны.
3. Размер изображений: чтобы были хорошо видны и при малом весе. Предварительно: формат WebP, для окон ворот не меньше 256 пикселей по короткой стороне (лучше 512).
4. Что делает стиль «мягким и профессиональным»: составить style-guide для интерфейса, цветов и дорожного мира.
5. Определить количество заданий и способ выбора (сколько взять из каждой категории).
6. Резервный вариант: один HTML-файл (для компьютера и проектора), если PWA не сработает.
7. Где будет размещена игра (бесплатный хостинг, например GitHub Pages) и кто отвечает за обновления?
8. Эко-картинки 117×166 PNG ~30 КБ: если размыто в игре, переделать (рекомендую 512×512 WebP).
9. Как перекрасить героев в экологическую тему и какие аксессуары им добавить (рюкзак, листик)?

## 12. Идеи на потом (не входят в первую версию)

- Бонусы: магнит, щит, замедление времени.
- Звуки животных при правильном ответе.
- Анимация радости героя на финише.

## 13. Журнал решений

| Решение | Что выбрано | Почему |
|---|---|---|
| Вид игры | **Настоящее 3D** (изменено 16.11.2026) | Готовые бесплатные 3D-герои с анимациями; один герой виден со всех сторон |
| Технология | **JavaScript + Three.js** (изменено 16.11.2026) | Работает в браузере и офлайн как PWA; Phaser рассчитан на 2D |
| Герои | **6 моделей KayKit, CC0** (было 4) | Бесплатно, с анимацией бега, виды спереди и сзади из одной модели |
| Офлайн | PWA | Работает без интернета на телефонах и компьютерах |
| Уровни | Три раздела по классам, без уровней внутри | Проще и понятнее |
| Ошибка | Окно краснеет, персонаж мерцает, мир серый и постепенно возвращается | Понятная реакция без лишнего наказания |
| Подсказка | Правильное окно зеленеет | Ребёнок видит правильный ответ и учится |
| Жизни | Три сердца; теряются за ошибку в ответе, удар в ограждение и падение в дыру | Понятная механика, дорога тоже важна |
| Дороги | Три дорожки, при двух вариантах третья закрыта | Всегда есть проход |
| Язык | Русский | Аудитория школы |
| Вопросы с животными | В 1-4 классах фото сверху для «Где живёт» и «Чем питается», в остальных только текст | Младшим нужна опора на картинку |

### Примечание про подсказку

Правильное окно показывается зелёным после ошибки. Из-за этого при повторных прохождениях ребёнок может запомнить ответ, а не понять тему. Если игра окажется слишком лёгкой, вернуться к этому решению.
